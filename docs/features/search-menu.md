# Feature Guide: Multi-Entity Global Search Hub (`/search`)

> **Route:** `http://localhost:3000/search`  
> **Purpose:** Unified 3-in-1 search across Candidate Database, Client Database, and Job Order Database.

---

## 1. Tab Overview
1. 👤 **Candidate Database:** Search 3,377+ candidate profiles with grouped contact points, blacklist detection, and direct profile links.
2. 🏢 **Client Database:** Search client companies, tax IDs, industries, contacts, and active job counters.
3. 📋 **Job Order Database:** Search open positions, locations, working modes, and client affiliations.
